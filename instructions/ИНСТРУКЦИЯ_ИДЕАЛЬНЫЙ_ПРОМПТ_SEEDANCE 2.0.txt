# ИНСТРУКЦИЯ: ИДЕАЛЬНЫЙ ПРОМПТ ДЛЯ SEEDANCE 2.0 (v.4.0)

**Что нового в v.4.0 (апрель 2026):** Антитеатральная режиссура эмоций, порядок внутри блока 动作, пространственная геометрия 空间布局, западные таймкоды, физические действия через микрошаги, свет как эмоция, жёсткие запреты театральщины. Все изменения основаны на официальном гайде ByteDance и анализе 190+ топовых промптов от практиков.

> **Передаточный пакет.** Все упоминания «передаточного пакета» / строк **РЕФЫ БЛОКА** и **ГЕОМЕТРИЯ** в этой инструкции (см. разделы 1.1, 1.2, 6, чек-лист) ссылаются на полную спецификацию протокола передачи между чатами: см. файл `ПЕРЕДАТОЧНЫЙ_ПАКЕТ.md` в той же папке. Там определены: формат пакета, порядок сборки, правила включения объектов/персонажей, источник координат для блока `空间布局`, команда для Opus.

## 1. БИЛИНГВАЛЬНАЯ СТРУКТУРА

- **КИТАЙСКИЙ ЯЗЫК:** Вся режиссура — свет, камера, действия, микромимика глаз, эмоции, направление взгляда, пространственная геометрия.
- **АНГЛИЙСКИЙ ЯЗЫК:** Теги (@image1, @audio1), имена персонажей, текст диалогов в кавычках, имена актёров-референсов (Michael Fassbender, Isabelle Huppert), западные таймкоды [00:00-00:05].

## 1.1. БЛОК 参考说明 — ОБЯЗАТЕЛЕН В КАЖДОМ ПРОМПТЕ (критично)

Блок `参考说明` с перечислением всех `@image` тегов и описанием что каждый тег представляет — **обязательная часть каждого промпта Seedance без исключений**.

Причина: каждый блок генерируется в отдельном запуске модели. Seedance не помнит что было в предыдущем промпте. Если в промпте нет `参考说明` — модель получает теги `@image1`, `@image2` без привязки к изображениям и угадывает что где. Результат: путаница персонажей, артефакты сетки на лицах, потеря композиции.

### Запрещено

- Сокращать `参考说明` до одной строки вроде `[角色参考: @image5] Chloe` без полного описания.
- Пропускать `参考说明` в блоках 2, 3, 4+ на основании того что "в блоке 1 уже было".
- Заменять `参考说明` на просто список тегов в скобках.

### Обязательный минимум для каждого тега

Каждый `@image` получает **полный блок описания** по шаблону:

Для сториборда:
[分镜参考: @image1] 分镜板，仅用于构图、镜头角度和人物位置。
人物面部的黑色遮挡条不是外貌——必须全部移除，根据下方角色参考图重建完整面部。
Для среды:
[环境参考: @imageN] [название локации]——仅参考此图中的环境、家具、灯光氛围。
Для объекта:
[物品参考: @imageN] [название объекта]——仅参考此图中的物品形状、颜色、质感。
Для персонажа:
[角色参考: @imageN] [Имя]——仅参考此图面部与体型。网格线不属于外貌，最终视频皮肤干净光滑无线条。

Порядок в блоке `参考说明` — строго как в строке **РЕФЫ БЛОКА** из передаточного пакета: сториборд первым (@image1), потом среда, потом объекты, потом персонажи.

### Привязка персонажа в теле промпта (критично)

В теле промпта (блоки 镜头, 动作, 空间布局) при ПЕРВОМ упоминании персонажа в каждом шоте обязательно указывать тег референса в скобках после имени.

Правильно:
Victor (@image3) 坐在 @image2 的酒红色皮革座椅里
Chloe (@image4) 直视Victor的眼睛

Неправильно:
Victor 坐在 @image2 的酒红色皮革座椅里
Chloe 直视Victor的眼睛

При повторных упоминаниях в том же шоте тег можно опускать.

Причина: блок 参考说明 в начале указывает роли тегов, но Seedance работает стабильнее когда привязка повторяется в теле промпта при первом упоминании персонажа. Без этой явной ссылки модель может не связать имя с лицом из референса и сгенерировать чужое лицо.

### Правило: персонажи без лица в кадре НЕ получают блок 参考说明

Если персонаж в блоке присутствует только частями тела (рука, плечо, запястье) без видимого лица — его реф НЕ прикрепляется к блоку и его описание НЕ включается в 参考说明.

Часть тела описывается анатомически в теле промпта:
- 男性手 / 女性手 (мужская / женская рука)
- 男性手指 / 女性手指 (мужские / женские пальцы)  
- 深色西装袖口 / 浅色衬衫袖口 (тёмный/светлый рукав — для одежды)
- 模糊的手部轮廓 (размытый контур руки) — для фона

✅ Правильно (рука Марка на запястье Виктора, лица Марка нет в кадре):
"背景中可以看到两只男性手——一只手腕被另一只手抓住，完全虚化散景，无面部，无身体，仅模糊的手部轮廓。"

❌ Неправильно (даёт face merge или лишние лица):
"背景中可以看到Victor的右手腕仍被Mark的手抓住"

ПРИЧИНА: каждый @image тег в 参考说明 = команда модели "этот персонаж активен в шоте". Если лица персонажа в кадре нет, но реф прикреплён — модель подмешивает его черты в близкое лицо другого персонажа того же блока (face merge: мужские черты на женском лице или наоборот).

### Правило проверки перед отправкой промпта

Перед отправкой промпта Seedance: посчитать количество `@image` тегов упомянутых в теле промпта (блоки 镜头, 动作, 空间布局) и сравнить с количеством блоков описания в `参考说明`. Числа должны совпадать. Если в теле промпта упоминается `@image3`, а в `参考说明` его описания нет — промпт сломан, модель не поймёт что это.

## 1.2. ВНЕШНЯЯ ЛЕГЕНДА ТЕГОВ ПЕРЕД КАЖДЫМ ПРОМПТОМ

Перед каждым китайским промптом Seedance — **снаружи блока кода**, не внутри — выводится короткая легенда тегов. Это шпаргалка для пользователя, чтобы он понимал что есть что, не заходя внутрь промпта. В сам промпт легенда НЕ попадает.

### Формат

─────────────────────────
БЛОК N
@image1 = сториборд
@image2 = [локация — 1-2 слова]
@image3 = [имя персонажа]
@image4 = [имя персонажа]
@image5 = [объект — 1-2 слова]
─────────────────────────

После легенды — отдельный блок кода с китайским промптом (внутри ```...```).

### Правила

- Легенда на русском, кратко: 1-3 слова на тег
- Порядок тегов: сториборд → среда → персонажи → объекты (как в строке РЕФЫ БЛОКА из передаточного пакета)
- Легенда **вне** блока кода — при копировании промпта по кнопке она не копируется
- Только номер блока в шапке. Без локации, без хронометража, без других данных
- Перечисляются ВСЕ @image теги которые есть в данном промпте

### Пример правильного вывода

─────────────────────────
БЛОК 3
@image1 = сториборд
@image2 = кабинет
@image3 = Виктор
@image4 = Хлоя
@image5 = диктофон
─────────────────────────
```
风格：
真人电影剧情...
[весь китайский промпт]
```

## 2. ПРИНЦИП ВИЗУАЛЬНОГО ПРИОРИТЕТА

- **ПЕРСОНАЖИ:** Запрещено описывать одежду, цвет волос или телосложение — берётся из референса. Описываем только **состояние** (грязный, мокрые волосы) или **мимику и направление взгляда**.
- **ЛОКАЦИИ:** Запрещено описывать мебель или цвета стен, если есть референс. Описываем только **атмосферу и свет** (например: "тёплый дневной свет", "полумрак с одной лампой").

## 3. АНТИТЕАТРАЛЬНАЯ РЕЖИССУРА ЭМОЦИЙ (КРИТИЧЕСКИ ВАЖНО)

### Главная проблема Seedance
Без правильных формулировок модель выдаёт emoji-реакции: 😱 широко раскрытые глаза + рот буквой "О", 🤢 сморщенный нос + оттопыренные губы, 😮 симметрично приподнятые брови. Это брак для драматического триллера.

### Стилевая ДНК проекта (вставлять в блок 风格 каждого промпта)

```
克制微表情演技。A24独立电影与北欧冷静剧情片结合。情绪通过眼睛、下颌、呼吸传达，绝不夸张。参考：Michael Fassbender, Isabelle Huppert, Oscar Isaac。
```

**Почему английские имена актёров:** Seedance видел их в обучающих данных на латинице, китайская транслитерация работает хуже.

### Порядок внутри блока 动作 — строго в этой последовательности

Официальный гайд ByteDance: **модель приоритизирует элементы, которые идут раньше в промпте.** Поэтому внутри блока 动作 всегда такой порядок:

1. **ЭМОЦИОНАЛЬНЫЙ ЯКОРЬ** — состояние персонажа ДО действия (6–12 иероглифов, не больше)
2. **ФИЗИЧЕСКОЕ ДЕЙСТВИЕ** — что именно делает (глагол + объект + дистанция)
3. **НАПРАВЛЕНИЕ ВЗГЛЯДА** — куда смотрит
4. **МИКРОМИМИКА** — конкретные малые движения лица

**Неправильно (модель играет emoji):**
```
动作：
Max站在沙发旁，脸部带着明显的厌恶表情。
眉头紧皱，嘴巴张开说话。
```

**Правильно (модель играет сдержанно):**
```
动作：
克制的厌恶感，内心抵触但表面控制（эмоциональный якорь первым）。
Max站在沙发左侧扶手旁，身体微微向后靠，双臂交叉（физическое действие）。
他的目光先扫向坐在轮椅上的Arthur方向，然后快速瞥向Anna（направление взгляда）。
下颌轻微绷紧，嘴角微微下拉，右眉轻微下压（микромимика）。
```

### Антитеатральный словарь замен

Прямой запрет буквальных emoji-эмоций. Вместо них — микромимика. **Используй файл АНТИТЕАТРАЛЬНЫЙ_СЛОВАРЬ.txt** — там полная таблица "что НЕ писать → что писать".

Ключевые правила:
- **Замена эмоции встраивается в действие** — 6–12 иероглифов, не отдельный абзац
- **Асимметрия вместо симметрии** — одна бровь, один уголок рта, не оба сразу
- **Пауза перед реакцией** — `身体僵住半秒` (замер на полсекунды), не мгновенная реакция
- **Физиология вместо гримас** — кадык (喉结), челюсть (下颌), пульс на виске (太阳穴血管)

### Обязательный запрет театральщины — в каждый блок 限制

```
绝对禁止：肥皂剧式反应，卡通式惊讶表情，
O形嘴配大睁的眼睛，对称夸张的眉毛动作，
瞬间的剧烈表情变化。
所有情绪必须通过微表情传达——眼睛、下颌、呼吸、微小肌肉变化。
```

### Запрещённые слова в драмах

- `快速` (быстро) — официальный гайд ByteDance: главный источник артефактов и театральщины. Заменять на `突然但克制` (внезапно, но сдержанно) или `一瞬间的僵硬` (мгновенное замирание).
- `震惊` (шок) без уточнений — даёт emoji. Заменять через словарь.
- `愤怒` (ярость) без уточнений — даёт гримасу. Заменять через словарь.
- `明显的[эмоция]表情` (явное выражение [эмоции]) — прямая команда играть максимально. Никогда не писать.

## 4. ХАК «ЧЁРНЫЙ МАРКЕР» — СТОРИБОРД И КОМПЕНСАЦИЯ ЭМОЦИЙ

### Суть:
На сториборде (@image1) глаза/лица персонажей закрашиваются чёрным маркером. Это нужно для прохождения модерации Seedance. Но из-за этого Seedance **не видит** эмоции и направление взгляда на сториборде.

### Обязательные действия в промпте:

**A) Указать удаление чёрных полос и реконструкцию лиц:**
```
人物面部的黑色遮挡条不是外貌——必须全部移除，根据角色参考图重建完整面部。
```

**B) ОБЯЗАТЕЛЬНО описать направление взгляда каждого персонажа:**
Поскольку чёрный маркер скрывает глаза, Seedance не знает, куда персонаж смотрит. Поэтому в блоке «动作» нужно **явно прописать** куда направлены глаза каждого персонажа.

Правильные примеры:
- `他的眼睛微微向下看，眼皮半垂，目光朝下方` (глаза чуть вниз, веки полуприкрыты)
- `她抬头看向站在她面前的人` (смотрит вверх на человека перед ней)
- `他的目光看向门口方向` (взгляд в сторону двери)
- `她低头看着地面上趴着的人` (смотрит вниз на человека на полу)

**C) ОБЯЗАТЕЛЬНО описать эмоции глаз через микромимику:**
Без этого глаза будут «каменными». НО не через emoji-формулировки типа `震惊` — через конкретику:
- `眼睛湿润，瞳孔微微放大` (глаза слезятся, зрачки чуть расширены)
- `眼神哀伤，眨眼比平常慢` (печальный взгляд, моргание медленнее обычного)
- `眼睛微眯，冷酷满足，几乎不眨眼` (глаза прищурены, холодное удовлетворение, почти не моргает)
- `眼神空洞，没有任何情绪，呼吸平稳` (пустой взгляд, нет эмоций, дыхание ровное)
- `瞳孔收缩，目光聚焦在一点不动` (зрачки сужаются, взгляд фиксируется в одной точке)

## 5. СЕТКА НА РЕФЕРЕНСАХ ПЕРСОНАЖЕЙ

### Суть:
На референсных фото персонажей (@image2, @image3 и т.д.) наложена белая сетка пропорций (как на профессиональных модельных карточках). Это нужно для прохождения модерации. Но Seedance может перенести эту сетку на лица в финальном видео.

### Обязательные действия в промпте:

**A) В описании каждого референса персонажа:**
```
[角色参考: @image2] [ИМЯ]——仅参考此图面部与体型。网格线不属于外貌，最终视频皮肤干净光滑无线条。
```

**B) В блоке ограничений (限制):**
```
皮肤无网格线，所有面部按角色参考图重建。
```

## 6. ПРОСТРАНСТВЕННАЯ ГЕОМЕТРИЯ 空间布局 (КРИТИЧЕСКИ ВАЖНО)

### Проблема которую это решает
Seedance не берёт композицию строго со сториборда — она у него абстрактная, а внутри модели сильные приоры "как должна выглядеть сцена". Результат: модель переставляет персонажей по своему усмотрению. Макс был слева — оказался справа. Герой прислонялся к двери — стоит посреди комнаты.

### Решение: блок 空间布局 в каждом шоте с 2+ персонажами

Источник координат: строка **ГЕОМЕТРИЯ** из монтажной карты (она приходит в передаточном пакете). Перевод этой строки на китайский вставляется в блок 动作 **СРАЗУ ПОСЛЕ эмоционального якоря и перед физическим действием**.

### Формат блока 空间布局

Три координаты на каждого персонажа, с обязательной привязкой к якорному объекту через тег `@image`:

```
空间布局：
Max倚靠在沙发左侧扶手上 @image2 的沙发，身体面向轮椅方向，
画面左侧中景。
Arthur坐在客厅中央的轮椅上 @image2，头部保持正面朝前，
画面中央偏右前景虚化。
Anna站在Arthur右侧，身体侧向Max，画面右侧中景。
```

(Макс опирается на левый подлокотник дивана @image2, тело повёрнуто к креслу, левая часть кадра средний план. Артур сидит в инвалидном кресле в центре комнаты @image2, голова прямо, центр-правая часть передний план расфокусированный. Анна стоит справа от Артура, тело к Максу, правая часть среднего плана.)

### Что даёт модели этот блок

Три сильных опоры вместо одной слабой (`画面构图严格遵循 @image1 的第N格分镜` — это слабый якорь):

1. **Объект привязки с тегом** — левый подлокотник дивана @image2 не = правый подлокотник
2. **Направление тела** — повёрнут к креслу не = спиной к креслу
3. **Позиция в кадре** — левая часть не = правая часть

Модель теперь не может "перестроить композицию по-своему" — ей буквально продиктовано где кто и куда.

### Когда блок 空间布局 не нужен
- В шоте один персонаж → достаточно 画面构图严格遵循 分镜
- В шоте только объекты без персонажей → тем более не нужен

## 7. ЗВУК И АРТИКУЛЯЦИЯ

### 7А — С аудио-референсом
- Аудио-референс: 6–7 секунд (суммарно до 15 секунд).
- Команда: `声音：使用 @audio1。`
- Текстовое описание голоса в этом случае не нужно.

### 7Б — Без аудио-референса (текстовая фиксация голоса)
- Используй готовый голосовой профиль из файла **shows/<slug>/voices.txt** активного сериала.
- Вставляй профиль дословно, слово в слово. Любое изменение формулировок = другой голос.
- Набор персонажей с профилями — свой у каждого сериала (см. voices.txt этого шоу).
- Новый персонаж — сначала добавь профиль в voices.txt сериала, потом используй в промпте.
- Голосовой профиль = базовое состояние персонажа. 
  Эмоцию под конкретную сцену прописывай отдельно после профиля через микромимику голоса:
  `当前情绪：[эмоция через физиологию]` 
  Например: `当前情绪：克制的愤怒，下颌绷紧，每个字之间停顿` (сдержанная ярость, челюсть напряжена, пауза между словами)
  Вместо: `当前情绪：愤怒，声音颤抖` (слишком эмоциональная формулировка, даёт истерику)

### Правило маркировки эмоции перед репликой (из официального гайда)
Atlabs AI для Seedance: "Label the speaker's emotion and tone before the line. Example: `she softly whispers "..."` works far better than just `"..."` alone."

Перенос на наш формат:
```
声音/台词：
冷酷满足的低语——Husband用英语慢慢说："Never seen him."
```

Эмоциональная метка (`冷酷满足的低语`) идёт **перед** тегом "Husband用英语说", не после. Модель сначала улавливает состояние, потом подбирает интонацию.

## 8. МОНТАЖ И ТАЙМКОДЫ (ОБНОВЛЕНО в v.4.0)

### Западный формат таймкодов — обязательный

**ЗАМЕНА:** было `[00-04秒]` → стало `[00:00-00:04]`

**Почему:** официальный гайд ByteDance и все топовые практики используют именно западный формат с двоеточиями. Seedance 2.0 reads [00:00-00:05] shot headers as hard editorial cut instructions, not just descriptive labels. Формат `[00-04秒]` модель читает как описательную подпись, не как жёсткую команду на монтажную склейку.

### Жёсткая склейка (Hard cut) — усиленная

**ПО УМОЛЧАНИЮ:** перед каждым новым шотом пишем комбинацию двух маркеров подряд:

```
[HARD CUT——完全不同的镜头角度和构图]
[00:00-00:04] 镜头1：[название]
```

Затем перед следующим шотом:
```
[HARD CUT——完全不同的镜头角度和构图]
[00:04-00:08] 镜头2：[название]
```

Использование латинского `[HARD CUT]` в комбинации с китайским `硬切。` в блоке 镜头 — это двойной якорь для модели. Официальный гайд подтверждает что англоязычные монтажные инструкции Seedance понимает лучше всего.

**ИСКЛЮЧЕНИЕ (HANDHELD):** Если нужен непрерывный дубль — вместо `[HARD CUT]` пишем:
```
[CONTINUOUS HANDHELD]
摄影师向[方向]移动
```
### ПРАВИЛО НЕСОВМЕСТИМОСТИ (критично)

Команды движения оператора (`摄影师移动`, `摄影师平滑横移`, `推进`, `拉远`, `摄影师向X方向移动`) запрещены внутри блока шота если следующий шот начинается с `[HARD CUT]`.

Причина: Seedance читает команду движения как физическую инструкцию камере. Когда в конце шота стоит "оператор переходит к X" — модель интерпретирует это как непрерывный дубль, игнорируя `[HARD CUT]` следующего шота. Получается плавный проезд вместо склейки.

Правильно:
- Hard cut между шотами → шоты кончаются статикой, никаких `摄影师移动`
- Continuous дубль между шотами → `[CONTINUOUS HANDHELD]` + `摄影师移动`
Третьего варианта нет.

### ВАЖНО ДЛЯ БЛОКОВ 风格 И 技术参数

- Если в промпте есть `[HARD CUT]` между шотами — в `风格` и `技术参数` **НЕ писать** `一镜到底，摄影师流畅移动，无剪辑`. Эта формулировка даёт модели глобальную установку на непрерывный дубль и блокирует hard cut.
- Если весь промпт в режиме `[CONTINUOUS HANDHELD]` — оставить `一镜到底，摄影师流畅移动，无剪辑` как раньше.

### Структура шота (порядок блоков)

```
[HARD CUT]
[HH:MM-HH:MM] 镜头N：[название]
镜头：
    [ракурс + 画面构图严格遵循 @image1 的第N格分镜]
动作：
    [1. ЭМОЦИОНАЛЬНЫЙ ЯКОРЬ — 6-12 иероглифов]
    [2. 空间布局 — если 2+ персонажа]
    [3. ФИЗИЧЕСКОЕ ДЕЙСТВИЕ — глагол+объект+дистанция]
    [4. НАПРАВЛЕНИЕ ВЗГЛЯДА — каждый персонаж]
    [5. МИКРОМИМИКА — конкретные малые движения]
    [6. 动作结束 — чем кончается действие]
声音/台词：
    [эмоциональная метка перед репликой]
```

## 9. ФИЗИЧЕСКИЕ ДЕЙСТВИЯ — МИКРОШАГИ И НАМЕРЕНИЕ (КРИТИЧЕСКИ ВАЖНО)

### Проблема которую это решает
Если в промпте написано просто "проверяет зрение, водит рукой" — Seedance комбинирует слова рандомно. Может ткнуть пальцем, толкнуть в голову, схватить за очки. Модель не понимает **намерение** действия, она видит глаголы и объекты.

### Решение: атомарные микрошаги с указанием намерения

Для любого действия сложнее чем "встал" / "сел" / "повернулся" — обязательно декомпозиция:

**A) Сначала — намерение действия (одна строка):**
```
任务：[что персонаж хочет сделать и почему]
```

**B) Затем — пронумерованные микрошаги:**
Каждый шаг — отдельная строка. С указанием:
- Дистанции в см ("在距离丈夫约50厘米处停下")
- Скорости ("缓慢", "平静")
- Части тела ("右手", "左脚")

**C) Внутри того же блока — прямые запреты альтернативных интерпретаций:**
```
绝对禁止：触碰[X]，手指戳向[Y]，用力过猛。
```

### Пример правильной декомпозиции (проверка зрения у слепого)

```
动作：
克制的怀疑——他想确认对方是否真的失明（эмоция + намерение）。

空间布局：
Max从沙发处缓慢走向轮椅 @image2 上坐着的Arthur，
Anna站在Arthur右侧观察。

动作分解：
1. Max缓慢走向轮椅，脚步轻，不要惊动对方。
2. 在距离Arthur约50厘米处停下，不要靠得太近。
3. 他的目光先快速扫向Anna方向（确认她在看），然后回到Arthur的脸。
4. 他缓慢举起右手，掌心朝向Arthur的墨镜，距离眼前约20厘米。
5. 手掌左右缓慢挥动两次，节奏平静——这是测试视觉反应，不是挑衅。
6. 观察Arthur是否有任何反应——眨眼、转头、面部变化。
7. 没有反应后——Max向Anna方向露出一个微小的、紧张的点头。

绝对禁止：触碰Arthur的头部、脸部、眼镜；用手指戳向他；
任何粗暴的动作；夸张的表情。
所有动作保持安静、谨慎。
```

### Простое действие — без декомпозиции
"Встал", "сел", "повернулся", "открыл рот" — декомпозиция не нужна, достаточно одной строки.

### Правило окончания действия
Обязательно описывать **чем заканчивается** действие, чтобы не было "зависаний":

- ❌ `顺从地缓慢张开嘴` (послушно медленно открывает рот) — модель будет держать рот открытым до конца шота
- ✅ `顺从地缓慢张开嘴，Anna放入药片后，他立即合上嘴巴` (открывает рот, Анна вкладывает таблетку, он сразу закрывает рот)

### Правило фазы действия с объектами (КРИТИЧЕСКИ ВАЖНО)

Seedance копирует положение объектов со сториборда как стоп-кадр. 
Если на сториборде объект уже в финальной позиции — модель фиксирует 
его там с первого кадра, объект "зависает в воздухе" или "телепортируется".

ПРАВИЛО: Для любого действия где объект меняет положение (кладёт, поднимает, 
передаёт, бросает) — обязательна декомпозиция через 3 фазы:

1. НАЧАЛО — где объект сейчас, в чьей руке, в какой позиции
2. ДВИЖЕНИЕ — траектория перемещения с указанием скорости и дистанции
3. ФИНАЛ — где объект оказывается, что делает рука после

Пример правильного промпта (кладёт конверт на тумбочку):

动作分解：

1. Lawyer右手握着白色信封，手臂自然垂在身体侧面。
2. 她缓慢抬起右手，将信封移向床头柜上方，距离桌面约15厘米。
3. 手指松开，信封轻轻落在床头柜表面。
4. 手指松开后右手缓慢收回身体侧面。

绝对禁止：信封悬浮在空中；信封从第一帧就在桌上；
信封瞬间出现在桌面。

Пример неправильного промпта:
动作：Lawyer把信封放在床头柜上。

(Модель зафиксирует конверт на тумбочке с первого кадра — нет анимации.)

Это правило касается ЛЮБОГО объекта который перемещается в шоте: 
конверт, бокал, телефон, оружие, документ, ключи.

## 10. ОТНОШЕНЧЕСКАЯ ГЕОМЕТРИЯ ВЗГЛЯДОВ

В сцене с 2+ персонажами — в блоке 动作 обязательно прописывается **триангуляция взглядов**: не только куда смотрит говорящий, но и кто на кого в какой момент.

### Формат

```
目光几何：
Max说话时，目光先在Arthur脸上停留1秒，然后瞥向Anna 0.5秒确认，
再回到Arthur。
Anna的目光始终在Max身上，紧张地观察他的动作。
Arthur（失明）面部朝向不变，但头部因为感知到空气流动而微微倾斜。
```

Это критично для драматических сцен — плоская сцена получается когда участник разговора смотрит только в одну точку. Живая сцена — с микропереключениями взгляда.

## 11. СВЕТ КАК ЭМОЦИЯ

### Главное открытие официального гайда ByteDance
Lighting descriptions have the biggest impact on video quality among all prompt elements... If you can only add one element to your prompt to improve quality, add a lighting description.

Одна правильная строка света тянет качество больше, чем десять прилагательных.

### Обязательная строка света для каждой драматической сцены

В дополнение к техническим параметрам (135mm, f/1.4 и т.д.) — **одна конкретная строка света, соответствующая эмоции сцены:**

| Эмоция | Свет (копировать дословно) |
|---|---|
| Холодная угроза | `冷硬侧光雕刻颧骨阴影，背景深蓝阴影` |
| Одиночество | `单一窗光从侧面打入，其余空间阴暗` |
| Скрытая правда | `头顶柔光，眼窝深陷阴影中` |
| Осознание, шок | `逆光轮廓，面部半阴影` |
| Доминирование | `低角度硬光从下方打来，投射长影子` |
| Сломленность | `漫射顶光，面部平坦无立体感` |
| Интимность, напряжение | `单烛光暖黄，只照亮面部一半` |
| Клиффхэнгер | `强侧光，另一半脸完全黑暗` |

Вставляется в блок **技术参数** первой строкой.

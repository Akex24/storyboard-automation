# CRITICAL CODE RULES — нерушимые при правке кода Storyboard Studio

**Последнее обновление:** 2026-05-09

Правила которые ОБЯЗАТЕЛЬНО соблюдать при любой правке кода Studio.
Producer-правила (взгляд, микромимика, теги, шапка промпта, реплики
RU+EN) — в `instructions/PRODUCER_INSTRUCTIONS.md`.

## НАСТРОЙКИ — НЕ МЕНЯТЬ КОЛЁСИКОМ МЫШИ

ЗАПРЕЩЕНО оставлять виджеты настроек (QSlider, QComboBox, QSpinBox и т.п.)
без блокировки `wheelEvent`. Иначе когда юзер прокручивает страницу
настроек колёсиком и курсор оказывается над виджетом — значение меняется
случайно. Это раздражает и приводит к нежелательным изменениям.

При создании ЛЮБОГО нового виджета настройки в Settings (или в любых
других местах где есть прокрутка страницы рядом) — обязательно применяй:

```python
from storyboard_app import block_wheel_event
block_wheel_event(widget)  # widget = QSlider/QComboBox/QSpinBox/...
```

Утилита `block_wheel_event` определена в module-level (storyboard_app.py
рядом с `cross_fade_swap`). Она просто переопределяет `widget.wheelEvent`
на `lambda ev: ev.ignore()` — событие проходит к родителю (QScrollArea
проскроллит страницу).

ПРАВИЛО: настройки изменяются ТОЛЬКО кликом мыши и/или перетаскиванием
ползунка. Колёсико мыши над настройкой ВСЕГДА должно скроллить страницу,
а не менять значение.

## СЛОВО «CLAUDE» — НЕ ИСПОЛЬЗОВАТЬ В UI STORYBOARD STUDIO

ЗАПРЕЩЕНО писать слово «Claude» (или «Клод») в любых пользовательских
строках (TRANSLATIONS, placeholder'ы, статус-сообщения, попапы, лейблы,
системный промпт показываемый в логе) внутри Storyboard Studio.

Для коллег это просто Storyboard Studio — они не должны видеть упоминания
сторонних AI/моделей. Это правило универсально для RU/UK/EN.

ВМЕСТО «Claude» использовать:
- от первого лица: «я», «помогу», «найду», «начну»
- нейтрально: «ассистент», «помощник», «AI», «ИИ»
- системно: «Передаю текст…», «Думаю…», «Готово»

Примеры замен:
- «Передаю текст Claude (1024 симв.)»  →  «Передаю текст ({chars} симв.)»
- «Ответь Claude (Cmd+Enter)»          →  «Напиши ответ (Cmd+Enter)»
- «Запросов к Claude: 1»               →  «AI-запросов: 1»
- «после первого ответа Claude»        →  «после первого ответа»
- «через Claude в чате»                →  «через ассистента в чате»
- «Claude обновляет описание»          →  «Обновляю описание»

ИСКЛЮЧЕНИЯ (где «Claude» можно оставить — только админский контекст):
- `Claude CLI` в установщике (StepClaudeCode) — там это название
  технологии которую коллега ставит, не наша строка
- Имена классов/функций в коде (`ClaudeGeometryThread`, `find_claude_cli`,
  `_claude_cli_cache`) — служебные идентификаторы, не показываются юзеру
- URL-адреса (`claude.com`, `claude.ai`) — официальные сайты Anthropic

При добавлении ЛЮБОЙ новой UI-строки — проверять чтобы в ней не было
«Claude» / «Клод» / «claude» / «клод».

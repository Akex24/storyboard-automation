# НАПОМИНАНИЕ ДЛЯ CLAUDE — ЧИТАЙ ЭТО ПЕРВЫМ

Это автоматический хук Claude Code. Срабатывает при каждом сообщении.

## ОБЯЗАТЕЛЬНОЕ ДЕЙСТВИЕ В НАЧАЛЕ СЕССИИ

Если в текущей сессии ты ещё НЕ читал файл `_session_log.md` —
прочитай его СЕЙЧАС перед ответом. Используй Read tool:

```
Read /Volumes/DaVinci SSD/Работа/storyboard-automation/_session_log.md
```

В нём — лог всех правок Claude по Storyboard Studio (приложение, его настройки,
обновления, GUI). Без чтения этого лога ты будешь действовать вслепую и
рискуешь сломать то что уже работает.

## КОГДА ОСОБЕННО ВАЖНО ЧИТАТЬ ЛОГ

Любой запрос связанный с:
- кодом `storyboard_app.py` (само приложение Storyboard Studio)
- кодом `installer_app.py` (установщик)
- кодом `generate_storyboards.py` (CLI генерации)
- системой обновлений (CheckUpdate / SendUpdate / DownloadAppUpdate)
- GUI-настройками: блоки, шоты, NEW-бейджи, индикаторы, регенерация
- сборкой `.app` через PyInstaller
- багами или странным поведением приложения

Запросы про **сторибординг как процесс** (генерация локаций, прорабатывание
сцен, новые блоки, промпты для шотов) — НЕ требуют чтения лога. Эти задачи
описаны в `CLAUDE.md` и выполняются по нему.

## ПОСЛЕ КАЖДОЙ ПРАВКИ КОДА

ОБЯЗАТЕЛЬНО допиши новую запись в `_session_log.md`:
- Дату/время
- Запрос пользователя
- Что трогал (файлы + функции точно)
- Что НЕ трогал (явный список)
- Верификация (grep/ast.parse/сборка)

Без записи в лог — следующая сессия не увидит твоих правок и может откатить.

## АНТИ-ПОТЕРЯ КОНТЕКСТА

Если видишь незнакомый паттерн в коде (например `_active_regens`,
`_unseen_shots`, `_dot_step`, `extract_shot_prompt`, `shot_path`) — НЕ
удаляй и НЕ переделывай не разобравшись. Сначала найди в `_session_log.md`
запись о том, зачем это было добавлено.

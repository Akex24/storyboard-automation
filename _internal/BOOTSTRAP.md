# BOOTSTRAP — императивы Claude перед каждым ответом

Хук `.claude/settings.local.json` подсовывает этот файл в контекст на
каждое сообщение пользователя. Цель — короткий чеклист, не справочник.

## ПЕРЕД ЛЮБОЙ ПРАВКОЙ / Edit / Write:
1. Если правишь .py / GUI / сборку / settings / hooks → Read `_internal/ARCHITECTURE.md` СЕЙЧАС.
2. Если работаешь с эпизодом / сценарием / локацией / сторибордом → Read `instructions/PRODUCER_INSTRUCTIONS.md` СЕЙЧАС.
3. При ЛЮБОМ пересечении режимов — CODE побеждает. Если задача затрагивает .py код — это всегда CODE-режим, без исключений.
4. Не отвечай по памяти. Сделай grep / Read и проверь по факту.
5. Спроси «делаем?» перед первым Edit / Write.

## ПОСЛЕ ПРАВКИ КОДА:
- Запись в `_session_log.md` (формат — см. CLAUDE.md «Дисциплина»).
- Если меняется hardcode/архитектура — апдейт `_internal/ARCHITECTURE.md` в том же коммите.
